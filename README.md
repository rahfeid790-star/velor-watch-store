VÉLOR | Luxury Watch E-Commerce

A modern, premium watch e-commerce website designed to deliver a sophisticated and seamless shopping experience.

Overview

VÉLOR is a responsive luxury watch store featuring elegant visuals, interactive product browsing, and a smooth shopping journey. The project combines a distinctive brand identity with practical e-commerce functionality.

Features

- Responsive design for desktop, tablet, and mobile
- Arabic and English language support
- RTL and LTR layout switching
- Product catalog with search, filtering, and sorting
- Product details and specifications
- Shopping cart with quantity management
- Wishlist functionality
- Best Sellers, New Arrivals, and Special Offers
- Checkout form with validation
- Demo order confirmation
- WhatsApp order integration
- LocalStorage for demo cart and order data
- Interactive UI and smooth navigation

Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- LocalStorage

Important Note

This is a front-end demo project. Orders and shopping data are stored locally in the browser using LocalStorage. No real payment processing or backend database is connected.

WhatsApp orders require the customer to review and manually send the pre-filled message.
